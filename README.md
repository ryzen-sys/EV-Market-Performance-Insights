# ⚡ Electric Vehicle Market Performance & Insights

## 📌 Project Overview
Electric Vehicle Market Performance & Insights is a data analytics project that explores the electric vehicle (EV) market using data visualization. The project analyzes EV sales, manufacturers, battery technologies, regional markets, and customer ratings to understand market trends and performance.

The project uses Tableau to create interactive dashboards and Flask to integrate the dashboard into a user-friendly website.

## 🎯 Project Objectives
- Analyze electric vehicle market trends.
- Compare manufacturers and their performance.
- Study battery technology distribution.
- Explore regional EV market performance.
- Analyze customer ratings and vehicle counts.
- Present insights through interactive visualizations.

## 🛠️ Technologies Used
- **Tableau Public:** Data visualization and interactive dashboard creation.
- **Python:** Backend programming.
- **Flask:** Web application framework.
- **HTML5:** Website structure.
- **CSS3:** Website styling and responsive design.
- **GitHub:** Source code management.
- **Render:** Website hosting and deployment.

## 📊 Dashboard Features
- EV sales trend analysis.
- Manufacturer-wise market analysis.
- Battery type distribution.
- Regional market comparison.
- Customer ratings analysis.
- Interactive filters for exploring the data.

## ⚙️ How to Run the Project Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/khuship9575/EV-Market-Performance-Insights.git
   ```

2. Open the project folder:

   ```bash
   cd EV-Market-Performance-Insights
   ```

3. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the Flask application:

   ```bash
   python app.py
   ```

5. Open your browser and visit:

   ```text
   http://127.0.0.1:5000/
   ```

## 🚀 Deployment
The Flask web application is deployed using Render. The Tableau Public dashboard is embedded into the website using an HTML iframe.

## 📌 Conclusion
This project demonstrates how data analytics and visualization can be used to understand electric vehicle market performance. By combining Tableau, Python, and Flask, the project provides an interactive platform for exploring EV market insights.
